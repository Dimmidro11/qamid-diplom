# Описание процедуры автотестов мобильного приложения «Мобильный хоспис».

## Предварительные действия:

Убедитесь, что на вашем устройстве установлены:
- **Android Studio**
- **Git** для клонирования репозитория
- **Allure** для генерации отчетов
- **Java JDK** (версия 11 или выше)

## Пошаговая инструкция

### Шаг 1: Клонирование проекта

1. Откройте терминал или командную строку
2. Передите в папку, куда желаете сохранить репозиторий (например, user/user/project)
написав: cd /user/user/project
3. Склонируйте репозиторий, указав адрес репозитория: https://github.com/Dimmidro11/qamid-diplom.git
4. 

### Шаг 2: Открытие проекта в Android Studio

1. Запустите Android Studio
2. Откройте склонированный проект
5. Дождитесь завершения синхронизации проекта

### Шаг 3: Запуск Gradle сборки проекта

Выполните сборку проекта

### Шаг 4: Создание эмулятора через Device Manager

В Android Studio откройте вкладку Device Manager и создайте новый эмулятор API 29 (Android 10).

### Шаг 5: Запуск тестов

В Android Studio выберите вид каталога «Project».
Перейдите в директорию `app/src/androidTest/java/ru.iteco.fmhandroid.tests`.
Правой кнопкой мыши кликните на папку `tests` и выберите опцию `«Run 'Tests in iteco.fmhandroid'»`, чтобы запустить все тесты данного пакета.
Для запуска отдельных тестовых классов выберите нужный тестовый класс и повторите предыдущий шаг.
Для запуска отдельного теста, откройте необходимый тестовый класс, в нем выберите тест, слева от теста кликните на символ Play. 

### Шаг 6: Копирование результатов тестов с эмулятора

После завершения тестов откройте окно Device Explorer эмулятора в Android Studio.
Перейдите в директорию `/data/data/ru.iteco.fmhandroid.ui/files/allure-results`.
Щёлкните правой кнопкой мыши на папке `files` и выберите опцию Save As....
Сохраните папку `allure-result` в корневую директорию вашего проекта.



### Шаг 7: Генерация HTML-отчета

1. Запустите команду в терминале для просмотра отчета:
 ```bash 
allure serve 
```

2. Отчет автоматически откроется в браузере.
