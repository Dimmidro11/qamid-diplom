# Отчёт по сравнению эффективности тестирования мобильного приложения "Мобильный хоспис"

**Дата:** 21.01.2026  
**Версия приложения:** 1.0.0

### 3. Результаты
#### 3.1 По времени

| Критерий | Ручное тестирование | UI-автотесты              |
| :--- |:--------------------|:--------------------------|
| **Время выполнения проверки** | ~60 минут           | **~7 минут**              |
| **Подготовка к запуску** | ~2 минуты           | ~0 минут*                 |
| **Повтор при изменении данных** | ~45 минут заново    | **~7 минут (перезапуск)** |
| **Итого на 5 прогонов** | **~300 минут**      | **~35 минут**             |

> `*` — подготовка автотестов (написание, поддержка) не учитывается, сравнивается только время запуска.

### 5. Ключевые выводы

1.  **Скорость:** Автоматизированный прогон **в 7-8 раз быстрее** разового ручного выполнения.
2.  **Масштабируемость:** При необходимости многократных прогонов (регресс, проверка на разных устройствах/данных) выигрыш автотестов становится **кратным и возрастает экспоненциально**.
3.  **Эффективность:** Автотесты исключают человеческий фактор, выполняются с одинаковой точностью и могут запускаться в нерабочее время.
4.  **Затраты:** Ручное тестирование требует постоянных временных затрат. Основные затраты автотестов — единовременное время на разработку и поддержку фреймворка.

### 6. Рекомендации

*   **Для регрессионного тестирования** критического сценария **целесообразно использовать UI-автотесты**.
*   **Ручное тестирование** оставить для:
    *   Исследовательского тестирования.
    *   Проверки сложных визуальных и UX-кейсов.
    *   Тестирования на ранних этапах, когда функционал нестабилен.

### 7. Заключение
